# SSC Shorts - Distraction-Free Study Feed

A fast, minimalist, and distraction-free Progressive Web App (PWA) designed for SSC exam aspirants to watch syllabus-oriented YouTube Shorts (Maths Tricks, Reasoning, English Rules, and General Awareness) along with a dedicated Break/Animals section.

## Features
- **100% Curated Exam Content**: Only genuine vertical YouTube Shorts covering Maths calculation shortcuts, Reasoning figure counting/dice/clock tricks, English grammar rules, and Static GK mnemonics.
- **Break Mode (Animals)**: A dedicated funny animal shorts feed to de-stress during study breaks.
- **Saved Library**: Save your favorite trick shorts and view them in a clean thumbnail grid view.
- **Infinite Random Feed**: Shuffle and play without algorithmic distractions, recommendation rabbit holes, or comments.
- **Responsive & PWA Ready**: Installable on mobile phones and desktop with offline app shell support.
- **Zero API Quota Limits**: Powered by YouTube embed player with no external server requirement.
